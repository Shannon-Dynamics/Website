REPOSITORIES

octo_map_rust

Pure-Rust port of OctoMap C++ 1.10.0 — 3D occupancy mapping with no unsafe code, no C++ toolchain, and byte-identical .bt/.ot file compatibility. 284 tests with bit-exact IEEE-754 comparisons against C++ fixtures.

RUSTAPACHE-2.0Repository ↗

scan_candi_with_octomap_rust

A MuJoCo drone orbits a temple, renders depth frames, and reconstructs a 3D occupancy map — rendering, mapping and visualisation all in Rust. Reference demo for octo_map_rust.
